# Product

This is a **personal banking** application. It is designed to help individual users manage their finances, track accounts, monitor transactions, and gain insight into their spending and saving habits.

## Core Purpose

- Provide a secure, user-friendly interface for personal financial management
- Allow users to view account balances, transaction history, and financial summaries
- Support budgeting, categorization, and financial goal tracking

## Target Users

Individual consumers managing their personal finances.

## Key Principles

- **Security first**: All financial data must be handled with strict security practices (encryption at rest and in transit, input validation, no secrets in code)
- **Accuracy**: Financial calculations must be precise and reliable
- **Privacy**: User data must never be exposed or leaked
